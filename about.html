Who Created Wazzup?

Wazzup was created by Pranjal Upadhyay.

Why Was Wazzup Created?

Wazzup was developed as a college project to explore web development, programming and real-time communication.

The aim of this project is to build a simple and modern messaging platform where users can connect and chat with each other.
